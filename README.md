# GTA V Mod Manager
To install, download the installer and run the exe and select where you want it to install to.

I made a very simple working mod manager for GTA V Enhanced.
I mostly built it for my own use to keep my game folder organized, but I thought I'd share it in case anyone else needs something similar. It essentially toggles your mods on/off by moving them to a temporary folder so you can launch a clean game instantly.
If you want to use it or contribute to the code, you're more than welcome to.
